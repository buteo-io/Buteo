# Screenshots

Add your Buteo screenshots here.

## Naming Convention

Use these names for the README to display correctly:

- `map-placeholder.png` → Map view screenshot
- `trips-placeholder.png` → Trip history screenshot
- `places-placeholder.png` → Places panel screenshot
- `share-placeholder.png` → Share link screenshot

## Recommended Screenshot Size

- Width: 800px
- Format: PNG with transparency or JPG

## How to Take Good Screenshots

1. Use the demo data to populate realistic trips
2. Use a browser width of ~1200px for consistent framing
3. Include the sidebar/panels for context
4. Add a subtle shadow or border for polish
